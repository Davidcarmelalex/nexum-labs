## What is Nexum Labs?

Nexum Labs is an AI-powered gamified learning studio where young creators master tomorrow's technologies through project-based missions. Build real projects, earn XP, unlock skills — not certificates.

## Quick Start

```bash
git clone https://github.com/Davidcarmelalex/nexum-labs.git
cd nexum-labs
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
```
